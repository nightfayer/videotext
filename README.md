# 🎬 Telegram Бот: Видео в Текст, Уникализатор & Оформление ТГ-постов

Многофункциональный высокопроизводительный серверный и локальный Telegram-бот:
* 🎙️ **Расшифровка аудио и видео в текст** с субтитрами `.srt` и документом Word `.docx` на базе **Faster-Whisper** (с ленивой загрузкой и выгрузкой из RAM при простое).
* ✨ **Уникализатор видео без потери качества** (`CRF 18`) с живым прогресс-баром для Instagram Reels, TikTok и YouTube Shorts.
* ✍️ **Умный копирайтер и редактор постов** с эстетичной типографикой Telegram (`<b>`, `<i>`, `<blockquote>`, `<code>`) на базе нейросети **Google DiffusionGemma 26B** (NVIDIA NIM).
* 📦 **Поддержка больших файлов до 2 ГБ** через высокоскоростной параллельный протокол MTProto (Telethon).

---

## ⚡ Режимы работы (переключение удобной клавиатурой 2х2):

```text
[ 🎙️ Видео в Текст ]   [ ✨ Уникализировать видео ]
[ ✍️ Написать ТГ-пост ] [     🚀 Меню / Старт     ]
```

### 1️⃣ 🎙️ Видео в Текст
* 🎥 **Любые видеофайлы:** `.mp4`, `.mov`, `.mkv`, `.avi`, `.webm` и др.
* ⭕ **Кружочки Telegram:** прямое извлечение звука и расшифровка видеосообщений.
* 🎵 **Голосовые и аудиофайлы:** `.mp3`, `.wav`, `.ogg`, `.opus`, `.m4a`, `.aac` и голосовые сообщения.
* 📄 **Результат в 4 форматах:**
  1. Текст прямо в чат с таймингами и процентом уверенности языка.
  2. Текстовый файл `.txt` с полными таймкодами.
  3. Файл субтитров `.srt` для видеомонтажа.
  4. Форматированный документ Microsoft Word `.docx`.

---

### 2️⃣ ✨ Уникализировать видео (для Instagram Reels, TikTok, Shorts)
* ⚡ **Аппаратное ускорение & 1-проходный рендер:** поддержка кодирования на GPU NVIDIA NVENC (до 8–10x быстрее реального времени) с бесшовным переключением на CPU `libx264`. Видео обрабатывается в 1 быстрый проход без лишних промежуточных файлов.
* 📱 **Безопасный 1080p даунскейл (RAM Safe):** автоматическое масштабирование тяжелых 4K роликов (например, снятых на iPhone) до стандартного Full HD 1080p в начале цепочки фильтров. Это устраняет OOM (Out Of Memory), экономит более 70% RAM и ускоряет рендеринг в 2–3 раза.
* 🛡️ **Аварийный fallback (Auto-Recovery):** если входящее видео имеет повреждённый контейнер или нестандартный формат, бот автоматически перехватывает сбой и запускает нормализацию.
* 📐 **Студийное качество:** визуально безупречный битрейт (`CRF 18` / `-cq 19`) без замыливания картинки.
* 🛡️ **Продвинутый комплекс Anti-Detect и обхода Content ID:**
  * **Спуфинг мобильных камер:** случайная генерация EXIF и QuickTime метаданных популярных флагманов (*iPhone 16 Pro, iPhone 15 Pro Max, Samsung Galaxy S24 Ultra, Google Pixel 8 Pro, Sony Alpha 7 IV, GoPro Hero 12*).
  * **Микро-срезка начальных миллисекунд (0.12–0.22 сек):** ломает совпадение по первому ключевому кадру (I-frame) и миниатюре (thumbnail).
  * **Микро-зум (2.0–2.8%) и кроп:** ломает пространственный визуальный отпечаток (pHash).
  * **Перцептивный шум и цветокоррекция:** частотное изменение пиксельной матрицы каждого кадра.
  * **Микро-виньетка:** невидимый для глаза градиентный сдвиг угловых блоков кадра.
  * **Акустический микро-эквалайзер и сдвиг темпа (`atempo`):** полная смена аудио-отпечатка Sound ID без слышимых искажений.
  * **🪞 Зеркальное отражение (Horizontal Flip):** переключение одной командой `/flip` для максимального обхода алгоритмов.
* 📊 **Живой прогресс-бар в реальном времени:**
  ```text
  ✨ Уникализация видео: 54%
  [█████░░░░░]
  ⏱️ 00:27 / 00:50 • Скорость: 7.83x
  ⚙️ Микро-зум, перцептивный шум, цветокоррекция, метаданные

  [ ❌ Отменить ]
  ```
* 🛑 **Кнопка «Отменить»:** моментально прерывает кодирование и очищает временные файлы без зависаний.

### 3️⃣ ✍️ Написать ТГ-пост (AI-редактор)
* 🧠 **Превращение любых черновиков в вирусный пост:** отправьте боту сырые мысли, тезисы, расшифровку или новость — он оформит их в идеальный пост для Telegram.
* 🎨 **Эстетичная типографика:**
  * <b>Жирный заголовок</b> и ключевые акценты.
  * <i>Курсив</i> для передачи эмоций, личных мыслей и тонких наблюдений.
  * <code>Инлайн-код</code> для локаций, брендов, артикулов и параметров.
  * <blockquote>Цитаты</blockquote> для главного инсайта или ключевой мысли.
  * Много «воздуха» между короткими абзацами (1–2 предложения) для комфортного чтения со смартфона.
  * Органичные эмодзи и релевантные тематические хэштеги.
* 🛠️ **HTML-санитайзер:** автоматическая балансировка и очистка тегов исключает ошибки парсинга Telegram.

### 4️⃣ 🚀 Меню / Старт & Нативное меню Telegram
* В клавиатуре закреплена кнопка **«🚀 Меню / Старт»** для мгновенного возврата к выбору режима.
* В интерфейсе Telegram зарегистрировано официальное меню команд **«Меню ≡»**:
  * `/start` — 🚀 Главное меню / Перезапуск
  * `/post <текст>` — ✍️ Оформить красивый ТГ-пост из любого режима
  * `/flip` — 🪞 Включить / выключить зеркальное отражение видео
  * `/help` — 📖 Подробная инструкция
  * `/settings` — ⚙️ Текущая конфигурация и параметры моделей

---

### 5️⃣ 🛡️ Автономность 24/7 и оптимизация ресурсов
* 🧹 **Фоновый сборщик мусора (Garbage Collector):** каждые 30 минут фоновый процесс проверяет директорию `temp/` и удаляет зависшие временные файлы старше 1 часа, предотвращая переполнение диска.
* 💤 **Автовыгрузка памяти (RAM Saver):** нейросеть Whisper загружается только при необходимости («ленивая» загрузка) и автоматически выгружается из оперативной памяти при простое более 10 минут, возвращая серверу ~1.2 ГБ свободной RAM для плавной работы видео-уникализатора.
* ⚡ **Параллельная 4-поточная загрузка (Fast MTProto):** скачивание файлов до 2 ГБ разбивается на параллельные потоки с корректным выравниванием чанков по протоколу Telegram, обеспечивая максимальную скорость загрузки без сбоев.

## 🛠️ Установка и запуск

### 1. Получение API-ключей

1. **Telegram Bot Token:**
   * Откройте [@BotFather](https://t.me/BotFather) в Telegram.
   * Выполните команду `/newbot` и скопируйте полученный токен.

2. **Telegram API ID & API Hash (для файлов до 2 ГБ):**
   * Перейдите на [my.telegram.org](https://my.telegram.org) и войдите по номеру телефона.
   * Откройте раздел **API development tools** -> создайте приложение -> скопируйте `api_id` и `api_hash`.

3. **NVIDIA NIM API Key (для генерации постов):**
   * Получите бесплатный ключ API на [build.nvidia.com](https://build.nvidia.com).

---

### 2. Настройка файла `.env`

Создайте файл `.env` (на основе `.env.example`):

```env
# Токен вашего бота от @BotFather в Telegram
BOT_TOKEN=123456789:AA...Ваш_Токен_От_BotFather

# API ID и API HASH от https://my.telegram.org (для файлов до 2 ГБ)
API_ID=12345678
API_HASH=abcdef0123456789abcdef0123456789

# Модель Whisper: tiny, base, small, medium, large-v3, turbo
WHISPER_MODEL=small

# Устройство: cuda (для GPU) или cpu
DEVICE=cpu

# Тип вычислений: float16 (для GPU) или int8 (для CPU)
COMPUTE_TYPE=int8

# Язык распознавания (пусто для автоопределения или 'ru', 'en')
WHISPER_LANGUAGE=ru

# Нейросеть для генерации ТГ-постов
NVIDIA_API_KEY=nvapi-...
NVIDIA_MODEL=google/diffusiongemma-26b-a4b-it
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1

# Белый список ID пользователей (оставьте пустым для общего доступа)
ALLOWED_USERS=
```

---

### 3. Запуск

#### Вариант А: Через Docker Compose на сервере (в 1 команду)
В проект встроен параметр `pull_policy: build`, поэтому Docker сам автоматически пересобирает образ при любых изменениях кода:
```bash
docker compose up -d
docker compose logs -f
```

#### Вариант Б: Локальный запуск на Windows (в 1 клик)
Просто дважды кликните по файлу **`run.bat`**.

#### Вариант В: Через командную строку (Linux / Windows)
```bash
python -m venv .venv
source .venv/bin/activate       # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

## 📋 Структура проекта

* [`bot.py`](bot.py) — главная точка входа, инициализация окружения, автопроверка FFmpeg и маршрутизация.
* [`bot_telethon.py`](bot_telethon.py) — основной движок бота на MTProto (файлы до 2 ГБ, очередь задач, живой прогресс-бар, инлайн-кнопки отмены).
* [`bot_aiogram.py`](bot_aiogram.py) — резервный fallback-движок на Bot API для работы без API ID/Hash (файлы до 20 МБ).
* [`post_formatter.py`](post_formatter.py) — генератор постов на базе Google DiffusionGemma, конвертер Markdown в Telegram HTML и санитайзер тегов.
* [`video_uniquifier.py`](video_uniquifier.py) — 1-проходный алгоритм уникализации видео через FFmpeg с безопасным масштабированием до 1080p и парсингом прогресса в реальном времени.
* [`transcriber.py`](transcriber.py) — модуль транскрибации речи (Faster-Whisper, ленивая загрузка, автовыгрузка из RAM после 10 минут простоя).
* [`fast_download.py`](fast_download.py) — параллельное чанковое скачивание файлов из Telegram на максимальной скорости сети.
* [`audio_utils.py`](audio_utils.py) — извлечение звука через FFmpeg (16 kHz mono WAV), генерация Word `.docx`, периодический сборщик мусора.
* [`config.py`](config.py) — валидация конфигурации и регистрация DLL CUDA.
* [`docker-compose.yml`](docker-compose.yml) & [`Dockerfile`](Dockerfile) — готовая контейнеризация для продакшн-сервера с авто-пересборкой.
