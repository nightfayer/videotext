# 🎬 Telegram Бот: Перевод Видео и Аудио в Текст (Faster-Whisper)

Локальный Telegram-бот для автоматической транскрибации речи из любых видеофайлов, видеосообщений (кружочков), голосовых сообщений и аудиозаписей. 

Работает на базе нейросети **Faster-Whisper** с аппаратным ускорением на видеокарте NVIDIA (CUDA) и поддержкой загрузки **больших файлов до 2 ГБ** через протокол MTProto (Telethon).

---

## ✨ Возможности

- 🎥 **Любые видео:** `.mp4`, `.mkv`, `.mov`, `.avi`, `.webm` и др. (отправленные как видео или как документ без сжатия).
- ⭕ **Кружочки в Telegram:** прямая расшифровка видеосообщений.
- 🎙️ **Голосовые и аудио:** `.mp3`, `.wav`, `.ogg`, `.opus`, `.m4a`, `.aac` и голосовые сообщения.
- 📦 **Файлы до 2 ГБ:** снято стандартное ограничение Telegram Bot API (20 МБ).
- 🚀 **Аппаратное ускорение на GPU:** поддержка CUDA + `float16` на видеокартах NVIDIA (RTX 3070 Ti и др.) — расшифровка в разы быстрее длительности видео!
- 📊 **Индикатор прогресса:** отображение процента скачивания файла прямо в сообщении.
- 📄 **Удобная выдача результата:**
  - Текст прямо в чате (с автоопределением языка и времени обработки).
  - Файл `.txt` с полным текстом и разметкой по таймкодам.
  - Файл субтитров `.srt`, готовый для видеоплееров и монтажа.
- 🧹 **Автоочистка:** временные файлы удаляются сразу после завершения распознавания.

## 🛠️ Быстрый старт

### 1. Получение ключей Telegram

Для поддержки файлов больше 20 МБ боту требуются три параметра в файле `.env`:

1. **`BOT_TOKEN`**:
   - Откройте бота [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot`, укажите имя и юзернейм бота.
   - Скопируйте полученный токен (вида `123456789:ABCdefGhI...`).

2. **`API_ID`** и **`API_HASH`**:
   - Перейдите на сайт [my.telegram.org](https://my.telegram.org) и войдите по номеру телефона своего аккаунта Telegram.
   - Выберите раздел **«API development tools»**.
   - Заполните поля `App title` и `Short name` (можно написать любое название, например `MyTranscriber`).
   - Нажмите «Create application».
   - Скопируйте поля **`App api_id`** (число) и **`App api_hash`** (строка).

---

### 2. Заполнение файла `.env`

Откройте файл [`.env`](.env) (или создайте его на основе [`.env.example`](.env.example)) и укажите ваши настройки:

```env
BOT_TOKEN=123456789:AA...Ваш_Токен_От_BotFather
API_ID=12345678
API_HASH=abcdef0123456789abcdef0123456789

# Модель Whisper: tiny, base, small, medium, large-v3, turbo
# По умолчанию установлена 'small' (высокая точность для русского языка)
WHISPER_MODEL=small

# Устройство: cuda (видеокарта) или cpu
DEVICE=cuda

# Тип вычислений: float16 (для GPU)
COMPUTE_TYPE=float16

# Белый список ID пользователей (только они могут использовать бота, оставьте пустым для всех)
ALLOWED_USERS=
```

---

### 3. Запуск бота

Вы можете запустить бота любым из способов:

#### Способ 1: Дважды кликнуть по файлу [`run.bat`](run.bat)

#### Способ 2: Через командную строку / терминал:
```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe bot.py
```

После первого запуска бот автоматически загрузит выбранную модель Whisper и напишет в консоли:
`✅ Бот успешно запущен и ожидает файлы в Telegram!`

## ⚙️ Выбор модели Whisper

В файле `.env` можно выбрать нужную точность:

| Модель | Размер | Скорость на GPU | Описание |
|---|---|---|---|
| `tiny` | ~75 МБ | Сверхбыстро | Базовое распознавание, минимальное потребление памяти |
| `base` | ~145 МБ | Очень быстро | Быстрая черновая расшифровка |
| `small` (по умолчанию) | ~480 МБ | Быстро | Отличный баланс скорости и высокой точности на русском языке |
| `medium` | ~1.5 ГБ | Средне | Высокая точность для сложного звука |
| `turbo` | ~1.6 ГБ | Очень быстро | Качество флагманской `large-v3`, но в разы быстрее |
| `large-v3` | ~3 ГБ | Медленнее | Максимальное качество распознавания |

## 📋 Структура проекта

- [`bot.py`](bot.py) — точка входа и выбор режима (Telethon или Aiogram).
- [`bot_telethon.py`](bot_telethon.py) — бот на MTProto Telethon с поддержкой файлов до 2 ГБ.
- [`bot_aiogram.py`](bot_aiogram.py) — бот на Aiogram для стандартного Bot API (до 20 МБ).
- [`fast_download.py`](fast_download.py) — многопоточная скоростная загрузка файлов чанками.
- [`transcriber.py`](transcriber.py) — модуль транскрибации речи (Faster-Whisper, генерация SRT и таймкодов).
- [`audio_utils.py`](audio_utils.py) — извлечение звука через FFmpeg (16kHz mono WAV), санитайзер имен и вспомогательные функции.
- [`config.py`](config.py) — чтение и проверка настроек из `.env`.
- [`run.bat`](run.bat) — запуск бота в 1 клик на Windows.
- [`.env`](.env) — файл с секретными ключами и настройками.
